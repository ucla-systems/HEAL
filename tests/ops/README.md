# Experiment Operation Scripts

Run long experiments through these bash entrypoints rather than typing runner commands directly. Set `RUN_STAMP` once when you want multiple tasks to share run ids.

```bash
export RUN_STAMP=$(date -u +%Y%m%dT%H%M%SZ)
export GPU_SLUG=NVIDIA_H100_80GB_HBM3
export GPU_LABEL=H100
```

MedQA generation defaults to `MEDQA_GENERATION_BATCH_SIZE=32`; the 32B runner caps itself at 16. Flip-rate generation is split into non-significand cases and the significand sweep so a machine can skip the expensive `k03..k23` generation. Override `MODEL_SELECTOR` for partial runs, for example:

```bash
export MODEL_SELECTOR="--model qwen3-8b"
```

Scripts:

- `01_medqa_reference.sh`: FP32 LayerCast MedQA generation artifacts.
- `02_error_contribution_policy.sh`: full calibration32 attribution, HEAL++ / HEAL-Full+ tuning, and policy export. Run on one calibration machine only when the policy must be regenerated.
- `02b_heal_policy_tuning.sh`: tune/export HEAL++ / HEAL-Full+ policy from existing attribution CSVs only. Use when attribution CSVs already exist and only thresholds or validation need refreshing.
- HEAL policy JSON files are generated by `02_error_contribution_policy.sh` or `02b_heal_policy_tuning.sh`; they are local artifacts and are not committed.
- `03_medqa_mse_flip_figures.sh`: MedQA final-hidden MSE replay and figure refresh. It does not run flip-rate generation; run `03c` and/or `03d` first when those rows are needed.
- `03a_medqa_native_triton_refresh.sh`: native BF16/FP16 MedQA reruns and plot refresh.
- `03b_medqa_flip_figures_only.sh`: plot refresh only; no generation.
- `03c_medqa_flip_other_generation.sh`: MedQA flip-rate generation for non-significand cases: LayerCast, native FP16/BF16, and HEAL-family modes.
- `03d_medqa_flip_significand_generation.sh`: MedQA flip-rate generation for the `significand_k03..k23` sweep only.
- `04_sharegpt_tables.sh`: ShareGPT serving matrix and LaTeX/data table refresh.
- `04a_sharegpt_native_triton_refresh.sh`: native BF16/FP16 ShareGPT reruns and table refresh.
- `04b_sharegpt_policy_refresh.sh`: only missing ShareGPT HEAL++ / HEAL-Full+ policy reruns and table refresh.
- `05_mcr_bench.sh`: MCR-Bench FP32 reference hidden dump, seven-configuration replay MSE, one chunked flip-rate generation round, mse-flip table export, and MCR-Bench execution-time export.
- `05a_mcr_bench_generate_round1_chunked.sh`: MCR-Bench flip-rate generation round 1; submits standard chunked batches.
- `05b_mcr_bench_generate_round2_full_batch.sh`: MCR-Bench flip-rate generation round 2; submits all prompts in one `vllm.generate()` call.
- `05c_mcr_bench_generate_round3_full_batch_reverse.sh`: MCR-Bench flip-rate generation round 3; submits all prompts in reverse order and rebuilds the mse-flip table with mean/std flip rates across the three rounds.
- `06_arith_vs_trunc.sh`: five-model 8-row MedQA operator-level arithmetic-vs-truncation generation, replay tensor dump, offline summary CSV/JSON export, and residual, BF16/trunc delta, and Shapley interval plot refresh.

Common inputs are defined in `common.sh`; every script prints each command before executing it. Set `OPS_DRY_RUN=1` to print commands without running the underlying experiment.
